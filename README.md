# 化妆品法规标准库

这是一个静态网页，可通过 GitHub Pages 发布。

## 本地预览

双击 `index.html`，或在此目录运行：

```powershell
python -m http.server 8000
```

## GitHub Pages 发布

1. 将本目录中的 `index.html` 和 `README.md` 上传到仓库根目录。
2. 打开仓库 **Settings → Pages**。
3. 在 **Build and deployment** 中选择 **Deploy from a branch**。
4. Branch 选择 `main`，文件夹选择 `/ (root)`，点击 **Save**。
5. 等待 GitHub 完成部署，网址通常为：

   `https://wishawolfinNorth.github.io/cosmetics_regulations/`

网页中的官方法规链接需要联网访问。
